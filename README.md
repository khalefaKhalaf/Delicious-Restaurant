# 🍽️ Delicious Restaurant - Website

A responsive, interactive front-end website for a modern restaurant built with pure Web technologies.

## 🚀 Features
- **Responsive Navigation Bar:** Mobile-friendly hamburger menu built with CSS and Vanilla JS.
- **Interactive Menu:** Real-time dish search and category filtering.
- **Table Booking Modal:** Dynamic modal interface for booking tables.
- **Contact Form:** Interactive contact form with client-side validation.

## 🛠️ Tech Stack
- **HTML5:** Semantic layout and structure.
- **CSS3:** Custom styles, Flexbox, and Media Queries for full responsiveness.
- **JavaScript (Vanilla JS):** DOM manipulation, event handling, and live search logic.
